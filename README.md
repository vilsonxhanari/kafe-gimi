# kafe-gimi

An early full-stack PHP project — a café management system with user authentication and an admin dashboard.

## What it does
- User registration and login system (`register.php`, `login.php`, `login_process.php`)
- Session management and logout (`logout.php`)
- Admin dashboard for managing users (`dashboard.php`, `add_user.php`, `edit_user.php`, `delete_user.php`)
- Modular PHP structure (`header.php`, `footer.php`, `menu.php`)
- MySQL database layer (`/db` folder)

## Built with
- PHP (procedural)
- MySQL
- HTML / CSS / JavaScript
- Bootstrap

## What I learned here
- How authentication flows work (register → hash → login → session)
- Structuring a multi-page PHP app with shared header/footer
- CRUD operations against a MySQL database
- The pain of managing users without a framework — which is why I later moved to Laravel and then WordPress
